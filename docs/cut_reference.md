# 宝石切型参考与实现目录

这批模型根据宝石学资料中的轮廓和切面家族重新建模，用于实时像素风展示。尺寸、角度与面数是本项目的创作参数，不代表工业切磨图纸或任何机构的评级标准。所有示意图标均由本地模型轮廓生成。

主要参考：

- [GIA：钻石结构](https://4cs.gia.edu/interactive-4cs/cut/anatomy.html)：台面、冠部、腰部、亭部与常见外轮廓。
- [GIA：形状与切面风格](https://4cs.gia.edu/en-us/blog/guide-diamond-shapes-engagement-rings/)：形状与切面排列的区别，明亮式、阶梯式以及异形切型。
- [GIA：宝石切割风格定义](https://hongkong.gia.edu/gia-website/gia-news-research-value-factors-gem-cutting-styles-definitions)：阶梯、混合和三角等切型的分类与变体。

| 切型 | 资料中的识别特征 | 本地建模安排 | 本地面数（含腰部） |
| --- | --- | --- | --- |
| 圆形明亮式 | 圆轮廓，放射状三角与风筝切面 | 多层冠部与交错亭部 | 74 |
| 椭圆形 | 拉长的圆弧轮廓 | 32 段腰部、细分冠部与交错亭部 | 146 |
| 水滴形 | 单尖端与圆润底端 | 32 段对称轮廓、肩部／尖端分面与交错亭部 | 136 |
| 马眼形 | 两端尖、两侧弧形 | 双尖透镜轮廓与独立切面 | 71 |
| 公主方形 | 尖角方形、明亮式切面 | 方形腰部、交错方位的亭部层次 | 50 |
| 祖母绿阶梯 | 切角长方形，平行的层层切面 | 八边腰部、三层冠部与三层亭部 | 58 |
| 阿斯切方阶梯 | 切角方形，较小台面 | 更宽切角、更深的阶梯与较高冠部 | 58 |
| 枕形 | 圆角方形、饱满弧边 | 超椭圆轮廓与明亮式切面 | 74 |
| 三角形 | 三角外形，有不同边缘与切面变体 | 三角腰部与三重对称明亮式排列 | 38 |

例如，GIA 对标准圆明亮式的描述有明确的标准面数；项目中的圆形是加入腰部与额外分面的风格化设计，因此界面展示实际生成的 74 面。

切型与宝石材料相互独立。“祖母绿阶梯”表示形状与切面排列，可以显示为无色、粉色、蓝色或自选颜色。

## 数据与扩展

`assets/gem/cut_catalog.json` 是切型目录。每项关联独立的 Blender 源文件、GLB、JSON 切面数据、轮廓图标与参考来源编号。

`tools/cut_geometry.py` 定义几何配方，`tools/build_cuts.py` 通过 Blender 生成资源。每个模型检查闭合流形、凸性、正体积和 192 面的光学容量限制；Godot 再次检查导入网格与光学平面一致性。可使用 `-- --cuts pear oval` 只重建这两种模型，保留其余十种外形。

水滴／椭圆细化的面数、配方与验证见 [精细切面说明](cut_refinement.md)。面数均包含腰部和额外分面，为项目的美术设计，不是 GIA 标准切型面数。

当前光学求交采用凸体平面算法。这一批选择九种适合该算法的闭合凸切型；有凹口的轮廓需要另外扩展求交方法。
